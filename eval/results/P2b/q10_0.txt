慢在 `x not in result`：**列表查找要逐个比较，最坏总时间是 O(n²)**。如果 10 万条数据全都不同，比较次数约为：

```text
0 + 1 + ... + 99999 ≈ 50 亿次
```

如果元素可哈希（如数字、字符串、由可哈希元素组成的元组），直接改成：

```python
def dedup(items):
    return list(dict.fromkeys(items))
```

字典通过哈希查找去重，**平均时间降到 O(n)，空间为 O(n)**，同时保留原顺序和每个值首次出现的元素。

如果元素是字典或列表，按业务规则提取可哈希的去重键，例如按字典的 `id` 去重：

```python
def dedup(items):
    seen = set()
    result = []
    for x in items:
        key = x["id"]
        if key not in seen:
            seen.add(key)
            result.append(x)
    return result
```

这里保留每个 `id` 首次出现的记录；去重键决定哪些数据视为重复。
