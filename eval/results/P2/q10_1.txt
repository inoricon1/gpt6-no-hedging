慢在 `x not in result`：每次都线性扫描列表，数据越多，后面的查重越贵，总体最坏是 **O(n²)**。

如果 10 万条数据都不同，总计约 **50 亿次元素比较**。

元素可哈希时（如整数、字符串、由可哈希元素组成的元组），直接改成：

```python
def dedup(items):
    return list(dict.fromkeys(items))
```

这会**保留首次出现的顺序**，平均时间复杂度降到 **O(n)**，空间复杂度为 **O(n)**。

如果元素是 `dict` 或 `list`，用业务唯一键去重，例如按记录的 `id`：

```python
def dedup(items):
    seen = set()
    result = []
    for x in items:
        key = x["id"]
        if key not in seen:
            seen.add(key)
            result.append(x)
    return result
```

这里的关键是让 `set` 负责查重，平均每次查询 **O(1)**。
