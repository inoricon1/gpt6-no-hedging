慢在这一句：

```python
if x not in result:
```

`result` 是列表，判断是否存在需要从头逐个比较。随着列表变长，每次查询都更慢。如果 10 万条数据都不重复，总共约需比较：

```text
0 + 1 + 2 + … + 99999 ≈ 50 亿次
```

因此最坏时间复杂度是 **O(n²)**。

如果元素可哈希（例如整数、字符串、由可哈希元素组成的元组），可以改成：

```python
def dedup(items):
    return list(dict.fromkeys(items))
```

它会**保留第一次出现的顺序**，利用字典进行去重，平均时间复杂度为 **O(n)**。

也可以显式写成：

```python
def dedup(items):
    seen = set()
    result = []
    for x in items:
        if x not in seen:
            seen.add(x)
            result.append(x)
    return result
```

两种写法都适合可哈希元素；第二种会额外维护一个集合。不要直接用 `list(set(items))`，它不保证原始顺序。

如果元素是列表或字典，它们不可哈希，需要先明确去重依据。例如，字典按 `id` 去重：

```python
def dedup(items):
    seen = set()
    result = []
    for x in items:
        key = x["id"]
        if key not in seen:
            seen.add(key)
            result.append(x)
    return result
```

注意，这里的语义是“相同 `id` 算重复”，与原函数比较整个字典是否相等有所不同。
